# Общие рекомендации по работе с Claude

1. Именовать вкладки в терминале. Я для этого в .zshrc прописываю команду:
```shell
export TAB_NAME="${PWD##*/}_$(( $(date +%H) * 60 + $(date +%M) ))_${(L)$(printf "\\x$(printf '%02x' $((RANDOM % 26 + 97)))")}"
```
- Она выставляет переменную окружения TAB_NAME равную имени текущей директории + номер текущей минуты с начала дня и случайную букву, чтобы вкладки легче было различать между собой
- В hook с нотификацией выводить имя текущей вкладки
